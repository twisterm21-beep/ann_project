# Версии сайта

| Тег | Содержимое |
| --- | --- |
| `v1.0.0` | Опубликованная оптимизированная версия до изменения дизайна |
| `v1.1.0` | Новый дизайн с сохранением всех текстов |

Версия указана в `VERSION`. Теги обозначают неизменяемые снимки. Архивы хранятся в `C:\ann_project\releases`. Git-история и теги пока локальные, в GitHub не отправлены.

## Откат оформления

Из корня проекта:

```powershell
.\tools\restore-version.ps1 -Version v1.0.0
```

Команда требует чистое рабочее дерево, сохраняет текущий коммит в ZIP, восстанавливает `index.html`, `styles.css`, `script.js`, `VERSION` и создаёт отдельный коммит. История сохраняется. Фотографии у этих двух версий общие. Служебные файлы хостинга не затрагиваются.

Проверка без изменения файлов:

```powershell
.\tools\restore-version.ps1 -Version v1.0.0 -CheckOnly
```

Возврат нового дизайна выполняется той же командой с `-Version v1.1.0`.

## Публикация

Локальный откат не изменяет продакшен. Перед публикацией или откатом на сервере нужно сохранить текущий `public_html`, загрузить выбранную версию и сверить контрольные суммы. `tools`, ZIP-архивы и этот документ публиковать не нужно.

Новый дизайн подготовлен локально; на момент его создания продакшен соответствует `v1.0.0` по HTML/CSS/JS. В ссылках на CSS и JS каждого оформления сохранена собственная версия кеша.
