# Школа экспертного туризма во Вьетнаме

Статический сайт профессионального обучения организации туров во Вьетнаме. HTML, CSS и небольшой JavaScript без сборки, npm-зависимостей и внешних шрифтов. Текущая локальная версия — **v1.2.0**. На хостинг она не опубликована.

## Локальный запуск

Из корня репозитория:

```sh
python -m http.server 8765 --bind 127.0.0.1
```

Откройте <http://127.0.0.1:8765>. Также можно открыть `index.html` напрямую в браузере.

## Структура

```text
index.html                 Содержимое страницы
styles.css                 Оформление и адаптивная вёрстка
script.js                  Мобильное меню, подсветка разделов, скрытый профиль наставника
assets/                    Оптимизированные фотографии WebP
VERSION                    Версия оформления
docs/RELEASES.md            История версий и откат
tools/check-site.py         Проверка страницы и её ресурсов
tools/check-browser.cjs     Проверка семи ширин в отдельном headless Edge
tools/restore-version.ps1   Локальный откат с резервной копией
```

Фотографии текущей версии имеют префикс `school-`; мобильная фотография первого экрана — суффикс `-small`. Авторы и лицензии: [PHOTO-SOURCES.md](docs/PHOTO-SOURCES.md). Прежние ресурсы сохранены для отката, но не отображаются в v1.2.0.

## Проверка

Требуются Python 3 и Node.js:

```sh
python tools/check-site.py
node --check script.js
node tools/check-browser.cjs ../releases/v1.2.0-checks
```

Для версий, в которых менялось только оформление, проверка может подтвердить сохранение текстов относительно выбранного Git-тега. **Для v1.2.0 сравнение с v1.0.0 не применяется: тексты намеренно заменены.**

```sh
python tools/check-site.py --compare-copy v1.0.0
```

Для визуальной проверки используйте ширины 1440, 1280, 1024, 768, 430, 390 и 375 px. Браузерная проверка сохраняет снимки секций и JSON-отчёт. Требуется установленный Edge; другой путь можно передать через `EDGE_BINARY`. Используется отдельный профиль, пользовательский браузер не изменяется.

## Версии

- `v1.0.0` — оптимизированная версия до изменения дизайна.
- `v1.1.0` — новый дизайн с теми же текстами.
- `v1.1.1` — уточнено кадрирование фотографии первого экрана: пальмы остаются видны.
- `v1.2.0` — школа экспертного туризма: новые тексты и дизайн, четыре блока программы, цена 30 000 ₽, FAQ, лицензированные фотографии и статистика с официальным источником.

`VERSION` относится к оформлению сайта. Изменения документации и организации репозитория могут идти отдельными коммитами после тега без изменения этой версии.

Инструкции: [версии и откат](docs/RELEASES.md).

## GitHub и продакшен

Отправка коммитов в GitHub и публикация сайта — отдельные действия. В этом репозитории не настроен автоматический деплой. По имеющейся истории последняя выполненная публикация соответствует `v1.0.0`. Версия `v1.2.0` подготовлена локально; сервер и домен в ходе её подготовки не изменялись.

Для публикации нужны только `index.html`, `styles.css`, `script.js` и `assets/`. Не загружайте `.git`, документацию, инструменты, архивы или локальные настройки подключения. SFTP-настройки и ключи хранятся вне репозитория и не входят в Git.

## Контент и подключения

Запрос программы, консультация и вопрос о поступлении ведут в `https://t.me/movetoviet2026`. Серверной формы и автоматической выдачи файла в исходном проекте нет. Успешная отправка или скачивание не имитируются.

Профиль наставника в `script.js` содержит поля `photo`, `photoAlt`, `name`, `experience`, `geography`, `competencies`, `story`. Секция показывается только при заполнении всех полей, `verified: true` и успешной загрузке фотографии. До этого она скрыта, включая режим без JavaScript. Отзывы не показаны.

До оплаты школе нужно подтвердить условия доступа к материалам, сопровождения и практической части. Реальных образцов учебных документов в репозитории нет. [Отчёт о версии](docs/V1.2.0-REPORT.md).
