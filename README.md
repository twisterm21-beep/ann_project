# Vietnam Business Incubator

Статический лендинг программы обучения организации туров во Вьетнаме. HTML, CSS и небольшой JavaScript без сборки, npm-зависимостей и внешних шрифтов.

## Локальный запуск

Из корня репозитория:

```sh
python -m http.server 8765 --bind 127.0.0.1
```

Откройте <http://127.0.0.1:8765>. Также можно открыть `index.html` напрямую в браузере.

## Структура

```text
index.html                 Содержимое страницы
styles.css                 Оформление и адаптивная вёрстка
script.js                  Подсветка разделов в меню
assets/                    Оптимизированные фотографии WebP
VERSION                    Версия оформления
docs/RELEASES.md            История версий и откат
tools/check-site.py         Проверка страницы и её ресурсов
tools/restore-version.ps1   Локальный откат с резервной копией
```

Мобильные изображения имеют суффикс `-small`. Полные WebP сохранены также для совместимости с оформлением `v1.0.0`. Неиспользуемые JPG и служебные файлы хостинга отсутствуют в текущей ветке; исторические файлы доступны в тегах.

## Проверка

Требуются Python 3 и Node.js:

```sh
python tools/check-site.py
node --check script.js
```

Проверка дополнительно может подтвердить, что все тексты сохранены относительно выбранного Git-тега:

```sh
python tools/check-site.py --compare-copy v1.0.0
```

Для визуальной проверки используйте ширины 320, 375, 680, 768, 1024 и 1440 px, переходы по меню и мобильную нижнюю навигацию.

## Версии

- `v1.0.0` — оптимизированная версия до изменения дизайна.
- `v1.1.0` — новый дизайн с теми же текстами.
- `v1.1.1` — уточнено кадрирование фотографии первого экрана: пальмы остаются видны.

`VERSION` относится к оформлению сайта. Изменения документации и организации репозитория могут идти отдельными коммитами после тега без изменения этой версии.

Инструкции: [версии и откат](docs/RELEASES.md).

## GitHub и продакшен

Отправка коммитов в GitHub и публикация сайта — отдельные действия. В этом репозитории не настроен автоматический деплой. Последняя выполненная публикация сайта соответствует `v1.0.0`; новый дизайн `v1.1.0` подготовлен для проверки.

Для публикации нужны только `index.html`, `styles.css`, `script.js` и `assets/`. Не загружайте `.git`, документацию, инструменты, архивы или локальные настройки подключения. SFTP-настройки и ключи хранятся вне репозитория и не входят в Git.
