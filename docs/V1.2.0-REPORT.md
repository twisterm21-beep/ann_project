HTML, CSS и JavaScript без сборки и npm. Страница — `index.html`, оформление — `styles.css`, навигация — `script.js`, изображения — `assets/`. В исходниках отсутствуют серверные формы, механизм скачивания программы, аналитика, юридические страницы и подключённый favicon. ## Что изменено

- `index.html`: новое позиционирование, первый экран, школа, формат, три сегмента аудитории, четыре открытых блока программы, рабочие материалы, семь этапов ученика, рынок, практическое применение, ценность программы, стоимость 30 000 ₽, восемь FAQ, контакты. Добавлены canonical, Open Graph и Twitter-метатеги.

- `script.js`: раскрывающееся меню до 1280 px, Escape и возврат фокуса, закрытие при переходе, сохранённая подсветка активного раздела. Подготовлен скрытый профиль наставника без вымышленных данных.

- `VERSION`: 1.2.0. Обновлены README, история релизов и `.gitignore`. Добавлен воспроизводимый инструмент `tools/check-browser.cjs`.

Откат требует чистого рабочего дерева, сначала создаёт резервный ZIP и затем отдельный коммит; история сохраняется. Старые и новые ресурсы остаются на месте. Публикация на сервер — отдельное действие.
