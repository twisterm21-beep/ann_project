# Версии сайта и откат

| Тег | Содержимое |
| --- | --- |
| `v1.0.0` | Оптимизированная опубликованная версия до изменения дизайна |
| `v1.1.0` | Новый дизайн с сохранением всех текстов |
| `v1.1.1` | Кадр первого экрана смещён к пальмам на компьютере и телефоне |
| `v1.2.0` | Школа экспертного туризма: новые тексты, дизайн, программа, FAQ, цена 30 000 ₽; локальная версия без публикации |

Теги обозначают неизменяемые снимки. Номер версии находится в `VERSION`. v1.2.0 сохранена локально, без отправки в GitHub или публикации. Последующие изменения документации и структуры репозитория не меняют содержимое тегов.

## Локальный откат

Из корня проекта в PowerShell:

```powershell
.\tools\restore-version.ps1 -Version v1.0.0
```

Команда требует чистое рабочее дерево, сохраняет текущий коммит в ZIP, восстанавливает `index.html`, `styles.css`, `script.js`, `VERSION` и создаёт новый коммит. История не переписывается. Фотографии, необходимые обеим версиям, сохранены в `assets/`. Документация, инструменты и настройки хостинга не изменяются.

Проверка без изменения файлов:

```powershell
.\tools\restore-version.ps1 -Version v1.0.0 -CheckOnly
```

Вернуть новый дизайн:

```powershell
.\tools\restore-version.ps1 -Version v1.1.1
```

Вернуть v1.2.0 после отката:

```powershell
.\tools\restore-version.ps1 -Version v1.2.0
```

Перед изменениями v1.2.0 сохранён отдельный архив `v1.1.1-before-v1.2.0.zip` в `C:\ann_project\releases`. Новые фотографии v1.2.0 имеют префикс `school-`; прежние ресурсы не перезаписаны. Поэтому переключение четырёх основных файлов сохраняет работоспособность обеих версий. Подробности: [отчёт v1.2.0](V1.2.0-REPORT.md).

Архив перед откатом создаётся в папке `releases` рядом с репозиторием. Для текущего рабочего каталога это `C:\ann_project\releases`. В этой папке также сохранены отдельные архивы `v1.0.0.zip` и `v1.1.0.zip`.

Эта команда предназначена для переключения оформления между указанными версиями. Если будущий релиз меняет состав ресурсов, процедура отката должна учитывать и эти ресурсы.

## Скачать снимок из GitHub

В разделе Tags выберите нужную версию и скачайте ZIP. Архивы старых тегов отражают структуру на момент их создания и могут содержать файлы, впоследствии удалённые из текущей ветки.

## Продакшен

Локальный откат и `git push` не изменяют сайт на хостинге. Последняя выполненная публикация соответствует `v1.0.0` по HTML/CSS/JS. Новый дизайн пока не опубликован. При приведении репозитория в порядок SFTP и файлы сервера не изменялись.

Перед отдельной публикацией или откатом на сервере сохраните текущий `public_html`, загрузите выбранную версию сайта и проверьте контрольные суммы. Заменяйте HTML после CSS, JavaScript и изображений. Служебную папку `.well-known` на хостинге сохраняйте. Не публикуйте документацию, инструменты или архивы.

## Проверка v1.1.0 (история)

Проверено в Chrome при ширинах 320, 375, 680, 768, 1024 и 1440 px: горизонтального переполнения и обрезанного текста нет. Проверены переходы по меню, активный раздел и загрузка изображений. Ошибок JavaScript не обнаружено. Все исходные текстовые фрагменты и их количество сверены автоматически.

Откат на `v1.0.0` и возврат на `v1.1.0` проверены на отдельной копии проекта: восстановленные файлы совпали с соответствующими Git-тегами.

## Проверка v1.2.0

Проверены семь ширин: 1440, 1280, 1024, 768, 430, 390 и 375 px. Горизонтального переполнения, наложений в шапке и ошибок JavaScript нет. Проверены изображения, якоря, меню, восемь FAQ с клавиатуры, фокус, режим reduced motion и доступность навигации без JavaScript. Снимки и JSON-отчёт сохранены в `C:\ann_project\releases\v1.2.0-checks`. Исходные тексты v1.1.1 намеренно заменены согласно новому позиционированию.
